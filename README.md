Entry for the make.fun competition **The Dog Reviews the Mailman** — one funny
one-line review a dog gives the mailman, under 200 characters.

## The line

> He knocks twice, runs away, and calls it a job. I have never respected a man less, or waited for one more.

(106 characters)

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed).
Python standard library only — no third-party packages.
